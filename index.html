A repeatable permission test

  1. Use a regular browser tab. Open this HTTPS URL directly in Chrome, Edge, Firefox, or Safari. Embedded previews can block APIs or change the permission context.
  2. Start with a fresh permission state. Open the site controls beside the address bar → Site settings / Permissions → reset the relevant permission, then reload. A new tab alone does not reset permissions.
  3. Run one experiment. Every request starts from a button click. You can dismiss a chooser or deny a prompt and still record its wording. Grants may also trigger an OS dialog.
  4. Record the full UI. Include title, body, buttons, origin, browser version, OS, locale, and prior grant state. Use your OS screenshot shortcut; the webpage cannot extract native dialog text.
  5. Separate results from observations. “Request resolved” means the API completed. It does not tell us whether a prompt appeared. Some capabilities auto-grant, reuse saved permissions, or only show a chooser.
  6. Export before closing. Notes and metadata live only in this tab’s memory. Export a JSON research log, or CSV observations. No captured files, clipboard contents, coordinates, audio, video, font names, or device identifiers are included.
What this lab does

Requests permissions and immediately releases media streams and XR sessions after a successful grant. Hardware choosers do not send device commands. File tests do not read file contents or modify files. The clipboard-write test explicitly replaces your clipboard with a fixed sample. Network tests contact only an endpoint you enter.

Special setups

Storage Access needs a helper hosted on a different site and prior interaction with it. Network tests need a reachable server you control. WebOTP needs an origin-bound SMS. XR, NFC, and device APIs may need compatible hardware. These requirements are shown inside each experiment.

Keyboard and pointer lock are included as comparison cases: Google’s March 2026 notice says their proposed permission prompts did not launch. Do not assume those APIs will show a permission dialog.

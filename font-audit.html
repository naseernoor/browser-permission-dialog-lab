Local Font Access audit

Font names and bytes stay in page memory. Only counts, field availability, and byte sizes appear in the log. No network transmission is implemented; CSP blocks connections.

1: check permission. 2: enumerate and choose Allow, Block, or close the native prompt. 3: read one font’s bytes. 4: reload and repeat. Revoke Local fonts in Chrome site settings, then retest. This page does not automatically request access.
